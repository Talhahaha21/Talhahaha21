<a href="https://github.com/Talhahaha21/SmartNotesDigitization">

```text
STATUS    : COMPLETE
TYPE      : OCR + NLP + MLOps
STACK     : Python / TrOCR / PaddleOCR / FastAPI
            Docker / Kubernetes / MLflow
```

An end-to-end OCR system designed to transform handwritten notes into editable digital documents.

```text
     HANDWRITTEN NOTES
            │
            ▼
     ┌───────────────┐
     │  OCR ENGINE   │
     │    TrOCR      │
     └───────┬───────┘
             │
             ▼
     ┌───────────────┐
     │ RECOGNIZED    │
     │     TEXT      │
     └───────┬───────┘
             │
             ▼
┌─────────────────────────┐
│       NLP PIPELINE      │
│                         │
│  → Summary              │
│  → Key Points           │
│  → Flashcards           │
└─────────────────────────┘
```

**Key Results**

* Fine-tuned Microsoft's **TrOCR** using the IAM Handwriting Dataset and custom samples.
* Built an NLP pipeline for summaries, flashcards, and key points.
* Developed a **FastAPI** backend.
* Containerized with **Docker**.
* Deployed with **Kubernetes**.
* Added **MLflow** experiment tracking.
* Achieved an **82% reduction in Character Error Rate** compared with the baseline OCR model.

## `PROJECT_04` → `LEAF AREA ESTIMATION`

```text
STATUS    : COMPLETE
TYPE      : COMPUTER VISION
STACK     : Python / YOLOv8 / OpenCV / Roboflow
```

An end-to-end computer vision pipeline for estimating real-world leaf area from RGB images.

```text
RGB IMAGE
    │
    ▼
TRAY DETECTION
    │
    ▼
PERSPECTIVE CORRECTION
    │
    ▼
REFERENCE STRIP CALIBRATION
    │
    ▼
LEAF DETECTION
    │
    ▼
SEGMENTATION
    │
    ▼
PIXEL → CM² CONVERSION
    │
    ▼
LEAF AREA
```

**Key Results**

* Created a custom leaf dataset.
* Collected manually measured ground-truth areas.
* Annotated images using Roboflow.
* Fine-tuned YOLOv8 using Kaggle and custom datasets.
* Implemented perspective correction.
* Implemented reference-strip calibration.
* Used a fixed **16 cm² reference strip** for physical scaling.
* Validated predicted areas against manually measured ground truth.
